User (2026-10-29): "io faccio proposte ma tu validale, non essere assertivo,
dimmi cosa ne pensi realmente in modo pragmatico". Said after a day in which
vision, scale to billions, counterfactual investigations, API dashboard and
three bilingual written products were recorded almost without objection.

**Why:** a coordinator that only records ideas adds no judgment; the user
wants a pragmatic partner who tests each idea against cost, feasibility and
the project's current state.

**How to apply:** for every proposal, first say whether and where it does not
convince (feasibility, sequencing, cost, scientific risk), with the smallest
achievable next step, then record it with those caveats. The pragmatic view
given that day: psychohistory is a multi-year research programme, so the first
real result should be a historical validation (Wrigley-Schofield England
1700-1750, or the Irish famine); billions are unrealistic with one database row
per person, aim at 10^4-10^5 first without closing the road to 10^6; the WWII
and AGI investigations are far off, the coup scenario is closer; start the
written outputs with one data-grounded report, generated in one language and
translated with a check, an automatic paper is a draft not a publication; the
API contract should wait for the data model to stabilise or ship as unstable
before 1.0; specs that fix the scientific model deserve the user's review.
