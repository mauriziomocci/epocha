User rule (2026-10-29), stated as fundamental and a priority: "dobbiamo essere
etici, è fondamentale e prioritario" and "solo materiale utilizzabile e mai
protetto da licenze non free".

**Why:** Epocha is an open-source scientific project (Apache-2.0) meant to
produce a publication; using material it has no right to use, or failing to
credit a source, would compromise both the project and the paper.

**How to apply (every session, every agent brief):**
- Ideas and background from papers and projects may be used, and are always
  cited (author, year, title or repository URL, date read).
- Material incorporated into Epocha (code, prompts, text, data, images,
  templates) only if its licence allows it and is compatible with Apache-2.0
  (permissive licences such as MIT, BSD, Apache-2.0, CC0, CC-BY with
  attribution). Never anything under non-free licences, and never copyleft
  code such as AGPL/GPL inside Epocha. When the licence is unknown, it is not
  usable until verified.
- Datasets for calibration and validation: check the licence and terms of use
  before downloading or committing them; cite them.
- The local knowledge-base skills built from copyrighted books held for
  personal use (two-scoops, ghezzi, kubernetes-patterns, diataxis, spencer)
  may guide reasoning but their content is never copied into Epocha.
- Every brief to a research or developer agent carries this rule.
