Plan 4 also inherits one obligation from Plan 3 — the emergency-flight trigger takes its starvation counter as an argument because no such field exists in the schema, so Plan 4 must create that storage before flight can fire in a live run.

The adversarial audit took four rounds, and it earned every one. Round 1 returned twenty-two findings against a suite that was already green at 308 tests — the worst being that Gaussian noise in the social-mobility rule pushed newborns past the end of the class ladder into the enslaved class, a quarter of the children of poor parents in a poor zone under the modern-democracy template, with no enslaved parent anywhere. Round 2 found that two of round 1's own fixes had introduced defects worse than what they repaired: a crash that rolled back an entire tick's inheritance batch, and a repair that reduced a spec-mandated propagation to zero in the famine scenario it was written for. Round 3 found that a test reported as closed multiplied by zero the very coefficient it claimed to pin. Round 4 broke the pattern — every functional mutation goes red, nothing escapes — and returned CONVERGED on 2026-08-05. Along the way the suite grew from 183 to 372 demography tests, and the remediation fixed mental health that was never inherited because the templates named a field that does not exist, loans that left a nationalized estate's credit book with the family, estate tax credited to a currency no spending path reads, a wage window that overstated steadily-employed zones by 20%, and a famine that generated a quarter of a million memory rows in a single tick. The verdict covers the code as scoped — not the eight DESIGN defects the code implements faithfully, which go to a separate work item with its own phase-2 gate. Chief among them: the polygenic kernel is not variance-preserving, so trait diversity collapses to 48.8% of the declared era distribution within three generations and every simulated society drifts toward homogeneity. All eight are now documented in whitepaper §4.1 as currently true of the model, with their measured magnitudes, rather than deferred silently.
